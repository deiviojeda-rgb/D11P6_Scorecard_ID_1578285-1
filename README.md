## Задание 1. Слова и предложения

Сначала подготовь сообщения к подсчёту. "Привет" и "привет" должны стать одним словом, а запятая — отделиться от соседних букв.

**Действие:** допиши в `src/t9.py`:

| Функция | Результат |
|---|---|
| `normalize(word)` | Строка в нижнем регистре, "ё" заменена на "е" |
| `tokenize(text)` | Список слов из текста |
| `split_sentences(text)` | Список предложений; каждое предложение — список слов |

Используй следующие правила:

- слово состоит из русских букв а–я, латинских букв a–z и цифр;
- дефис остаётся внутри слова, если с обеих сторон от него буква или цифра: "чё-то", "по-моему", "21-й";
- остальные символы разделяют слова;
- точка, `!`, `?`, `…` и перевод строки разделяют предложения;
- несколько таких знаков подряд считаются одной границей; пустые предложения выбрасываются.

Например:

```
split_sentences("Я щас выйду. Подожди у входа.")
# [['я', 'щас', 'выйду'], ['подожди', 'у', 'входа']]
```

**Как обрабатывать разговорные написания.** Сохраняй слова так, как они написаны, с учётом нижнего регистра и замены "ё". Поэтому "щас" и "сейчас" останутся разными словами, "чё" превратится в "че", "сёдня" — в "седня". Сокращения ("кмк", “спс”) остаются отдельными словами. Исправлять орфографию и раскрывать сокращения в этом проекте не требуется.

**Что происходит с точками в сокращениях.** Пока действуют простые правила: точка всегда завершает предложение. Поэтому сокращение "т.п." разделится. Например:

```
split_sentences("Возьми воду, салфетки и т.п.")
# [['возьми', 'воду', 'салфетки', 'и', 'т'], ['п']]
```

Это ограничение выбранного способа разбора. Сохрани его, чтобы все функции работали с одинаковыми данными.

**Проверка:**

```
python3 checks/acceptance.py --task 1
python3 -c "from src.t9 import read_sentences; print(read_sentences('datasets/tiny.txt'))"
```

`read_sentences` уже написана: она читает файл и вызывает твою `split_sentences`. Открой `tiny.txt` и сравни текст с результатом разбора.

**Результат:** функции задания работают; ты можешь объяснить, какие слова и предложения получились, зачем нужна нормализация и какие различия она сохраняет или стирает.

## Задание 2. Частоты и дописывание слова

Теперь посчитай, сколько раз встречается каждое слово.\
Если человек набрал "при", программа найдёт все слова с таким началом и предложит самые частые.

**Действие:** допиши функции:

В `top_k` сортируй по убыванию частоты, а при равенстве — по алфавиту. Это правило понадобится во всех следующих заданиях.

В `complete` убирай пробелы по краям префикса и вызывай `normalize`. Пустой префикс подходит ко всем словам. Если кандидатов нет, верни пустой список. Остальные условия есть в описании функции.

В общих частотах наверху окажутся (скорее всего) "и", "не", "в" и другие слова, нужные во множестве реплик. Отдельно сравни частоты "сейчас" и "щас", "спасибо" и "спс": по выбранным правилам у каждого написания свой счётчик.

## Задание 3. Пары слов

После "можешь" и после "я" нужны разные продолжения. Чтобы это учесть, посчитай пары соседних слов — **биграммы**.

Для каждого слова сохрани, какие слова встречались сразу после него и сколько раз. Программа будет выбирать подсказку из этих продолжений.

Каждое предложение дополняется маркерами: `<s>` — начало, `</s>` — конец. Предложение "я щас выйду" даёт пары `<s> → я`, `я → щас`, `щас → выйду`, `выйду → </s>`.

**Действие:** допиши функции:

| Функция | Результат |
|---|---|
| `count_pairs(sentences)` | Словарь `{слово: {следующее слово: число появлений}}` с маркерами |
| `next_words(word, pairs, k)` | До `k` самых частых продолжений после `word`, без `</s>` |

Слово, которое передают в `next_words`, сначала приведи к виду слов в словаре пар — вызови `normalize`. Тогда «Можешь» и «можешь» дадут одну и ту же подсказку. Если такого слова в корпусе не было, верни пустой список. Чтобы узнать, с каких слов чаще всего начинаются предложения, передай вместо слова маркер `<s>`.

**Проверка:**

```
python3 checks/acceptance.py --task 3
python3 demo.py next можешь --corpus datasets/chats_2000.txt --k 3
python3 demo.py next давай --corpus datasets/chats_2000.txt --k 3
python3 demo.py next --corpus datasets/chats_2000.txt --k 3
```

Последняя команда показывает слова, с которых чаще всего начинаются предложения.

**Результат:** программа подсказывает продолжение по одному предыдущему слову. Ты можешь выписать пары для короткого предложения, объяснить назначение маркеров и показать, откуда взялась подсказка.

## Задание 4. N-граммы и откат

Теперь учти несколько предыдущих слов. После “можешь прислать” программа сможет предложить, что именно прислать, а не просто частое слово после “прислать”.

Слова перед местом подсказки \- это **контекст**. Чем длиннее контекст, тем конкретнее запрос. Но примеров для него может не оказаться вовсе или оказаться недостаточно

Переход к более короткому контексту называется “**откатом”**, или **back-off**.

**N-грамма** — последовательность из `n` слов. Для выбора следующего слова используется контекст из `n − 1` предыдущих:

| n | Контекст |
|---|---|
| 1 | Пустой: только общие частоты |
| 2 | Одно предыдущее слово, как в задании 3 |
| 3 | Два предыдущих слова |
| 4 | Три предыдущих слова |

Перед кодом разбери сквозной пример в `materials/model.md`: там показаны все словари для двух коротких предложений, поиск контекста и выбор продолжения.

**Действие:** допиши функции:

| Функция | Результат |
|---|---|
| `count_ngrams(sentences, n)` | Частоты продолжений для контекстов из `n − 1` слов; при `n = 2` результат совпадает с `count_pairs` |
| `build_model(sentences, max_n)` | Модели всех уровней от 1 до `max_n` в одном словаре |
| `context_for(history, n)` | Последние `n − 1` слов через пробел; при нехватке слева добавляются `<s>`; при `n = 1` возвращается пустая строка |
| `find_context(history, model)` | Пара `(n, контекст)` для самого длинного известного контекста либо `None` |
| `predict(history, model, k)` | До `k` самых частых слов после найденного контекста, исключая `</s>` |

Это, кстати, самое сложное задание дня. Начни с `count_ngrams` и `context_for`, затем собери модель, добавь поиск контекста и подсказку. Точные форматы словарей и правила добавления маркеров описаны в заготовке.

**Проверка:**

```
python3 checks/acceptance.py --task 4
python3 demo.py predict "можешь прислать" --corpus datasets/chats_2000.txt --k 3
python3 demo.py predict "я пока" --corpus datasets/chats_2000.txt --k 3
python3 demo.py predict "синий трамвай" --corpus datasets/chats_2000.txt --k 3
python3 demo.py predict "я пока" --corpus datasets/chats_2000.txt --n 2 --k 3
python3 demo.py predict "я пока" --corpus datasets/chats_2000.txt --n 4 --k 3
```

Для “синий трамвай” модель должна откатиться к общим частотам: проверь по выводу, какой контекст она нашла.

Демонстрационная программа показывает, какой контекст нашёлся. Сравни результат при `n = 2`, `n = 3` и `n = 4`. Без параметра `--n` используется 3\.

Откат в `predict` происходит, когда контекст незнаком. Если контекст найден, но после него был только конец предложения, подсказка пустая. Это ожидаемое поведение.

**Результат:** программа подсказывает следующее слово по контексту и сокращает контекст при необходимости. Ты можешь разобрать её решение на своём примере и объяснить, почему увеличение `n` не всегда помогает.

**Обязательная часть закончена.** Работают два режима: дописывание слова по префиксу и подсказка следующего слова по контексту.

## Задание 5 Bonus. Генерация текста

Если выбирать продолжение, добавлять его к истории и повторять выбор, получится целая фраза.

Реализуй два способа (названия \- кальки с английского):

- **“жадный”:** всегда выбирать самый частый вариант;
- **“случайный”:** выбирать с учётом частот, чтобы частые слова выпадали чаще редких.

**Действие:** допиши функции:

| Функция | Результат |
|---|---|
| `generate_greedy(start, model, max_words)` | Начальные слова и продолжение, выбранное жадным способом |
| `pick_random(counts, rng)` | Одно случайное слово; вероятность пропорциональна частоте |
| `generate_random(start, model, seed, max_words)` | Начальные слова и случайное продолжение; одинаковый `seed` даёт одинаковый текст |

Маркер `</s>` участвует в выборе наравне со словами. Если выбран он, генерация заканчивается. `max_words` ограничивает количество добавляемых слов; начальные слова в этот лимит не входят.

В `pick_random` соблюдай порядок выбора из описания функции: он нужен для воспроизводимого результата. Генератор `random.Random(seed)` создаётся один раз в начале `generate_random`.

**Проверка:**

```
python3 checks/acceptance.py --task 5
python3 demo.py greedy я --corpus datasets/chats_2000.txt
python3 demo.py random я --corpus datasets/chats_2000.txt --seed 7
python3 demo.py random я --corpus datasets/chats_2000.txt --seed 8
python3 demo.py random давай --corpus datasets/chats_2000.txt --seed 7
```

Запусти случайную генерацию с одним и тем же `seed` дважды и убедись, что текст повторяется. Попробуй другие начала и значения `seed`.

В результате нет заглавных букв и пунктуации: при подготовке текста они не сохранились. Программа также может соединить фрагменты разных реплик. Найди примеры удачных и странных сочетаний и объясни их через контекст и частоты.

**Результат:** работают оба способа генерации, одинаковый `seed` воспроизводит текст. Ты можешь объяснить остановку на маркере конца и причину повторов, если они появились.

Выбери тему, отличающуюся от основной переписки, чтобы было интересно сравнить подсказки. Личные данные и чужие частные сообщения в репозиторий не включай.
3. Создай `src/keyboard.py`, которая читает выбранный корпус, собирает модель и принимает строки в цикле:
   - по умолчанию используется `src/my_corpus.txt`;
   - путь к другому корпусу передаётся первым аргументом;
   - для каждой строки печатается до трёх подсказок `suggest`;
   - пустая строка или Ctrl+D завершают программу без ошибки.

В `suggest` учитывается только последнее предложение набранной строки. Если последний символ — буква или цифра из разрешённого набора, последнее слово считается недописанным. Если строка заканчивается пробелом или другим разделителем, подсказка относится к следующему слову. Подробные правила есть в описании функции.

Здесь откат продолжается, пока не найдутся слова с нужным началом. Это отличается от `predict`, которая останавливается на первом известном контексте, даже если после него встречался только `</s>`.

**Проверка:**

```
python3 checks/acceptance.py --task 6
python3 demo.py suggest "можешь при" --corpus datasets/chats_2000.txt --k 3
python3 demo.py suggest "я пока " --corpus datasets/chats_2000.txt --k 3
python3 src/keyboard.py
python3 src/keyboard.py datasets/chats_2000.txt
```

Обрати внимание на пробел в конце "я пока ": он означает, что слово "пока" уже закончено.
