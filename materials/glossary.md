# Словарь

**Биграмма** — пара соседних слов: «можешь прислать».

**Генерация** — построение текста последовательным выбором продолжений. В этом проекте программа выбирает следующее слово и добавляет его к истории, пока не выберет конец предложения или не достигнет лимита.

**Жадная генерация** — генерация, в которой всегда выбирается самое частое продолжение.

**Закон Ципфа** — наблюдаемая во многих текстах закономерность: частота слова приблизительно обратно пропорциональна его месту в списке слов, упорядоченных по убыванию частоты. Это приближённая зависимость, а не правило для каждого корпуса.

**Контекст** — данные, по которым модель выбирает продолжение. На уровне n-грамм в этом проекте это `n − 1` последних слов истории с маркерами начала при необходимости. При `n = 1` контекст пустой.

**Корпус** — набор текстов для работы с языком. Обучающий корпус используется для построения модели, проверочный — для оценки её качества.

**Маркер** — служебный токен, которого нет в тексте: `<s>` — начало предложения, `</s>` — конец.

**N-грамма** — последовательность из n соседних токенов. Униграмма содержит один токен, биграмма — два, триграмма — три. В проекте токены — слова и добавленные маркеры начала и конца предложения.

**Нехватка данных (data sparsity)** — ситуация, когда для некоторых контекстов в обучающем корпусе нет примеров или их слишком мало для надёжного выбора продолжения.

**Откат (back-off)** — переход к более короткому контексту. В `predict` он нужен, если контекст неизвестен. В `suggest` поиск продолжается и тогда, когда контекст известен, но после отбора по началу слова не осталось кандидатов для подсказки.

**Языковая модель** — модель, которая оценивает вероятности последовательностей токенов. В проекте она выбирает продолжение по частотам слов и их сочетаний.

**LLM (large language model)** — большая нейросетевая языковая модель. В материалах проекта сравнение относится к генерирующим LLM, которые последовательно выбирают следующие токены. Их устройство и обучение существенно сложнее подсчёта частот.

**Seed** — начальное значение генератора случайных чисел. Одинаковый seed при одном алгоритме и порядке вызовов позволяет повторить последовательность случайных чисел.

**Температура** — настройка случайной генерации, которая меняет распределение вероятностей следующих токенов. При низкой температуре выбор сильнее сосредоточен на наиболее вероятных вариантах; при высокой больше шансов у менее вероятных. В этом проекте температура не реализуется.

**Токен** — единица, с которой работает модель. В проекте это нормализованное слово или служебный маркер. У нейросетевых моделей токен может соответствовать целому слову, части слова, знаку препинания или другой последовательности символов.

**Top-k** — k лучших вариантов. В проекте их выбирает функция `top_k`: по убыванию частоты, при равенстве — по алфавиту.

**Точность top-k** — доля проверяемых позиций, в которых настоящее следующее слово попало в k подсказок модели. Это мера качества; её не следует путать с функцией `top_k`, которая отбирает варианты.
