# Приёмы Python для проекта

Здесь собраны приёмы, которые пригодятся в проекте. Для примеров достаточно стандартной библиотеки Python: ничего устанавливать не нужно.

## Словарь-счётчик

Словарь — набор пар «ключ — значение». Чтобы посчитать, сколько раз встречается каждое слово, увеличивай значение по ключу:

~~~python
счётчик = {}
for слово in ["кот", "спит", "кот"]:
    счётчик[слово] = счётчик.get(слово, 0) + 1
print(счётчик)          # {'кот': 2, 'спит': 1}
~~~

`счётчик.get(слово, 0)` возвращает текущее значение, а если ключа ещё нет — 0.

Для подсчёта можно использовать `collections.Counter` — подкласс `dict`, который хранит счётчики элементов:

~~~python
from collections import Counter

частоты = Counter(["кот", "спит", "кот"])
print(частоты["кот"])   # 2
~~~

Если нужен обычный словарь, его можно получить через `dict(частоты)`. Независимо от способа подсчёта сохраняй формат результата, описанный в функции.

## Словарь словарей

Для пар слов нужен словарь, в котором значения — тоже словари:

~~~python
пары = {}
первое, второе = "кот", "спит"
внутренний = пары.setdefault(первое, {})   # взять словарь для «кот» или создать пустой
внутренний[второе] = внутренний.get(второе, 0) + 1
print(пары)             # {'кот': {'спит': 1}}
~~~

`setdefault(ключ, значение)` возвращает значение по ключу. Если ключа нет, сначала кладёт туда переданное значение.

## Сортировка по нескольким признакам

`sorted` принимает функцию `key`: по её результату и сортируется список. Если результат — кортеж, сравнение идёт по первому элементу, при равенстве — по второму и так далее.

~~~python
частоты = {"б": 2, "а": 2, "в": 5}
пары = sorted(частоты.items(), key=lambda пара: (-пара[1], пара[0]))
print(пары)             # [('в', 5), ('а', 2), ('б', 2)]
~~~

Минус перед числом даёт «по убыванию частоты», а слово вторым элементом — «при равенстве по алфавиту». `частоты.items()` — пары `(ключ, значение)`.

Строки в Python сравниваются по кодам символов. Для русских букв без «ё» это обычный алфавитный порядок. Поэтому «ё» мы заранее заменяем на «е».

## Срезы

~~~python
слова = ["я", "не", "знаю"]
print(слова[-2:])       # ['не', 'знаю'] — два последних
print(слова[:1])        # ['я'] — первое
print(слова[1:])        # ['не', 'знаю'] — всё, кроме первого
~~~

Ловушка: `слова[-0:]` — это не «ноль последних», а весь список, потому что `-0 == 0`. Если нужно взять `m` последних элементов, а `m` может быть нулём, используй `слова[-m:] if m else []`.

Если `m` больше длины списка, `слова[-m:]` вернёт весь список. Для `context_for` проверь оба случая: `m = 0` и `m` больше длины истории. Если слов не хватает, недостающие маркеры `<s>` добавляются отдельно.

## Регулярные выражения

Модуль `re` ищет в тексте куски по шаблону. Для этого проекта хватит двух функций:

~~~python
import re

re.findall(r"[а-я]+", "кот, пёс и ёж")
# ['кот', 'п', 'с', 'и', 'ж'] — «ё» не входит в диапазон а–я

re.split(r"[.!?]+", "Да! Нет?! Может.")
# ['Да', ' Нет', ' Может', ''] — разрезать по разделителям
~~~

- `[абв]` — один любой символ из перечисленных; `[а-я]` — диапазон.
- `+` — «один или больше раз подряд».
- `(?:...)` — группа без сохранения; `(?:-[а-я]+)*` — «ноль или больше раз: дефис и буквы».
- `\n` внутри шаблона — перевод строки.

Использовать регулярные выражения не обязательно: можно идти по тексту символ за символом и собирать слово в цикле.

## Случайность, которую можно повторить

~~~python
import random

генератор = random.Random(21)   # свой генератор с seed = 21
print(генератор.random())       # число от 0 до 1, каждый раз одно и то же при seed = 21
~~~

Создавай свой генератор `random.Random(seed)` внутри функции, а не вызывай `random.seed(...)`: так генерация не зависит от того, что ещё в программе пользуется случайностью.

## Чтение ввода в цикле

~~~python
while True:
    try:
        строка = input("> ")
    except EOFError:          # Ctrl+D
        break
    if строка == "":
        break
    print("Ты набрал:", строка)
~~~

## Импорт своего модуля из соседнего файла

`src/keyboard.py` лежит рядом с `src/t9.py`. Если запускать его как `python3 src/keyboard.py`, Python ищет модули в папке запускаемого файла, поэтому работает обычный `import t9`.

Чтобы вызвать функцию из корня репозитория прямо в терминале:

~~~bash
python3 -c "from src.t9 import tokenize; print(tokenize('Кто-то пришёл'))"
~~~
